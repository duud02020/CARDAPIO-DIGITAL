# Fotos do cardápio OISHII

Coloque nesta pasta os 20 arquivos WebP do pacote entregue pela NEXORA.

Os nomes são associados aos códigos em `src/data/menu.js`.
Fotos 16–20 foram associadas à ordem dos pratos restantes; confirme os nomes com o restaurante antes da publicação definitiva.

Caso uma imagem ainda não tenha sido enviada, o site mostrará um espaço "Foto em breve" em vez de uma imagem quebrada.

A pasta `images/pratos/` precisa ficar na raiz do repositório.
